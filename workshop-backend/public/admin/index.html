“From” shows the IP address of the computer that sent it, the approximate city and country, and the network name. A red mark means that computer (same IP address, or the same browser) sent scores under more than one index number: use it to spot one person submitting for several students. A shared IP address can also be a whole lab or a campus network, so check the browser mark (the second one) before drawing conclusions. Same network = same tag: label it once (for example “Campus Wi-Fi” or “Home”) in the Networks table and every record from it shows that name, so you can see at a glance who sent from the university and who from home. Scores are kept until you delete them.
